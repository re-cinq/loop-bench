The token is read as the first offered value that is not the marker, in either order, and still reaches tools as `authHeaders.authorization`. `credentialFromSubprotocol`, also newly exported, reads it the same way for your own `WsAuthenticator`. **Migration note**: every client must be updated to offer `hal.v1` alongside its token, and an authenticator that took the first `Sec-WebSocket-Protocol` value as the token now gets `hal.v1` from an updated client, so read it with `credentialFromSubprotocol(req.headers['sec-websocket-protocol'])` instead.

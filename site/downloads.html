WHAT CAN I DOWNLOAD?
  • results.jsonl: every record we wrote, one per line, in a plain text format that most tools can read. It holds each model attempt and each finished run with its result, the changes it made and the AI reviewer's scores. If a run was scored again, it appears twice and the last record is the one that counts.
  • bench.json: the summary these pages read. It has every run with its task, model, knowledge base, ticket, cost, time and result, plus the totals per model and per setup. Costs are list prices for the tokens used.

Both files are rebuilt from the same records, so the pages and the downloads always agree.

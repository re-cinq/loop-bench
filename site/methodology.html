WHY WE MEASURED

The implementation loop's stations (dod, tdd-round, repair-build) each run on a model nobody chose by measurement. This bench replays merged tickets from their base commit with each harness and model, with and without the Lore MCP server, and repeats every cell so a lucky run shows as spread rather than as a rank.

HOW A CELL IS BUILT
  • One factor at a time. A cell varies one station against the production baseline; every other station stays at baseline. A cell is the ticket, the station varied, the model, its effort, Lore on or off, and the prompt variant.
  • Each run starts from a bare origin with main at the ticket's base commit. The subject's CI commands run locally on the pushed head between rounds.
  • Agents are the bare claude, gemini and codex CLIs under a scratch HOME with only credentials copied in. Runs work under /var/tmp/loop-bench/runs, and a run refuses to start when any instruction file sits above that folder.
  • Prompts are the bodies of lore's loop-*.md agent defaults at a pinned commit.
WHAT EACH METRIC MEANS
  • Reached green: the loop ended with the subject's CI checks passing on the pushed branch.
  • Rounds: tdd rounds the loop spent; 12 is the budget.
  • Cost: each model's token counts at its standard market price per million tokens, with no launch or promotional discounts. Subscription runs show what the same tokens cost on the API.
  • Judge: a fixed model's 1 to 5 scores for correctness, completeness against the issue, and closeness to the merged pull request. Judge mean averages the three.
  • dod red→green: the agent's acceptance tests failed on the base commit and passed once the merged pull request's production code was applied.
  • Files and Jaccard: files the branch touched, and the overlap of that set with the merged pull request's files.
  • Dominated: another cell of the same ticket and station is at least as cheap, as fast and as well judged, and strictly better on one of them.
LIMITS
  • Local CI is one Node version on one machine, not GitHub's matrix.
  • Codex has no Bash guard, so its rounds may run acceptance tests the others are refused.
  • In the with-Lore arm every station of the loop has the Lore MCP server, the tdd rounds included, so a with-or-without difference is Lore's effect on the whole loop.
  • In the with-Lore arm the Lore memory holds episodes from the real runs on these tickets.
  • Until a cell has repeats, a difference between two cells can be a lucky draw. The judge alone has moved a loop's score by a point when asked twice.
  • Runs made before 2026-10-19 22:30 loaded the author's personal Claude instructions and are archived, not shown here.
